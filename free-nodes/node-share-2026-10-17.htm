什么是蓝灯（Lantern）？

蓝灯是一款基于点对点（P2P）网络技术并结合现代代理与加密算法开发的网络访问加速工具。它的主要目标是：帮助用户绕过互联网审查和封锁，畅游原本无法触及的网络空间。蓝灯不是传统VPN，但在功能层面却具备类似能力，尤其适合想要“轻量科学上网”的用户。

与传统VPN相比，蓝灯更加注重“速度”和“简便性”——不需要注册繁杂账号、不需要手动配置路由器端口，也无需选择冗杂的协议。对于不具备技术背景的普通用户而言，蓝灯的使用体验极其友好，开箱即用。

蓝灯的核心功能与优势

1. 匿名与隐私保护

蓝灯通过隐藏用户真实IP地址，实现匿名化浏览，防止网络行为被追踪和分析。它不会记录用户的上网日志，也不会出售任何数据给第三方，保障个人隐私安全。

2. 稳定连接，高速上网

蓝灯采用智能路由分流机制，会自动寻找并连接当前网络环境下速度最佳的节点。它在全球多个地区均布有中继服务器，可大幅度提升连接稳定性及访问速度，尤其适合浏览网页、观看视频或处理跨境数据传输。

3. 多平台支持

蓝灯目前兼容Windows、macOS、Linux、Android等主流操作系统。用户只需登录蓝灯官网或官方渠道，即可选择适配版本，无缝跨平台使用。

4. 免费与付费模式并存

蓝灯提供免费版本以满足基本科学上网需求，同时推出付费版本（称为“专业版”），为追求更高速度、稳定性和功能完整性的用户提供更优质服务。免费用户虽有速度和时间限制，但足以应对轻量使用场景。

Q：免费版与付费版差别大吗？

Q：蓝灯记录用户数据吗？

Q：可以在手机上使用蓝灯吗？

FAQ

Matsuri 的节点测速结果能影响策略组吗？
可以。Matsuri 会将延迟最低的节点自动标记为优先节点，结合策略组，程序会优先选择最佳节点处理流量，保证访问速度和连接稳定性。
Mellow TUN 模式与 SOCKS5 代理有什么区别？
TUN 模式拦截系统 IP 层流量，实现全局代理；SOCKS5 代理通常只影响指定应用。TUN 更适合全局加速，如游戏、视频和浏览器流量，提高网络稳定性和覆盖范围。
Nekoray 如何导入 V2Ray 节点？
打开 Nekoray 客户端后，点击“导入配置”，选择 V2Ray 或 Clash 类型的订阅链接。程序会自动解析节点列表，用户可一键连接或进行延迟测试。
Matsuri 节点延迟排序功能如何使用？
Matsuri 会定期测速节点延迟，并结合策略组自动选择延迟最低节点。用户无需手动切换即可保持高速访问，优化网页、视频和游戏体验，提高网络稳定性。
Matsuri 是否支持延迟排序节点？
支持。Matsuri 会自动测试节点延迟并按结果排序。用户可快速选择延迟最低或速度最快的节点，提高网络访问速度，尤其适合游戏或视频场景。
Surfboard 能否同步 Quantumult X 的规则？
Surfboard 的规则语法与 Quantumult X 相似，但并非完全兼容。部分策略组或脚本需手动修改格式方能正常使用，因此不建议直接复制，最好通过转换工具处理。
如何为 Vmess 节点生成安全的 UUID？
UUID 应使用标准的 128 位格式，可使用系统命令如 `uuidgen` 或在线 UUID 生成器生成随机、唯一的 ID；不要使用默认或弱随机值，定期更换以降低被滥用或泄露的风险。
V2Ray 的 TCP + TLS 模式适合什么场景？
TCP + TLS 模式可模拟 HTTPS 流量，增强抗封锁能力。适合网络封锁严格的环境，通过策略组选择最佳节点，可保证访问速度和连接稳定性，尤其适用于网页浏览和视频播放。
Hiddify Next 的用户管理面板有哪些功能？
Hiddify Next 面板可添加或删除用户、设置带宽限制、生成订阅链接、查看流量统计和节点状态。它提供直观的图形界面，无需命令行操作即可管理服务器资源。
如何使用 Clash 配置订阅链接？
在 Clash 中添加订阅链接时，用户需复制提供的 URL 并在客户端的配置界面中粘贴。Clash 会自动下载并更新配置文件。通过订阅，用户可以一键更新节点信息，无需手动导入，适合长期维护多个节点来源的用户。
